# OFGUI pour Windows

Télécharger la dernière version portable :

**[Télécharger OFGUI](https://github.com/ecilalice75/ofgui-releases/releases/latest/download/ofgui-portable.zip)**

Décompressez entièrement le ZIP, puis lancez `ofgui.exe`. Le dossier `bin` doit
rester à côté de l'exécutable.

À partir de la version 0.2.0, OFGUI vérifie automatiquement ce dépôt au
démarrage. Les mises à jour sont signées, téléchargées en arrière-plan, puis
appliquées à la fermeture de la fenêtre. La configuration, les sessions et le
dossier de téléchargement choisi restent dans `%LOCALAPPDATA%\ofgui` et ne sont
pas supprimés par une mise à jour.
